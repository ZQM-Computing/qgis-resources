# Security policy

## Supported version

Security fixes are applied to the `main` branch. This repository contains resources and code snippets for QGIS/QField; it is not a hosted service.

## Reporting a vulnerability

Email **zqmcomputing@gmail.com** with the subject `qgis-resources security` if you find a problem in a snippet or script here — for example code that could damage a user's project data when run as documented. Please do not open a public issue for a sensitive report.

Include the affected file, the impact you observed, and reproduction steps when available.

## A note on running snippets

PyQGIS and Processing snippets run with your QGIS privileges on your data. Read a snippet before running it (they are short and commented by design), and work on a copy of production layers when trying anything new.
