# Environmental GIS figure-set brief and acceptance worksheet

**ZQM Computing — reusable scoping aid.** This is a template for discussions with
environmental consultants, engineers and project managers. It is not a price
quotation, booking, statement of professional opinion or commitment to a
delivery date. Start with non-sensitive information; arrange permitted transfer
and handling before sharing confidential data.

Use this worksheet with the [synthetic two-parcel sample](../exhibit-production/BUYER_HANDOFF_SAMPLE.md),
the [environmental exhibit review notes](RANK1_EXHIBIT_PRODUCTION.md) and the
[QGIS Atlas workflow](../exhibit-production/README.md).

## 1. Request and reviewing responsibility

| Required decision | Buyer-provided detail / recorded agreement |
| --- | --- |
| Intended use | Report type, planning question, decision audience |
| Study geography | General area first; parcel IDs/boundaries by agreed secure transfer |
| Figure inventory | Figure IDs, titles, number of parcels, map themes and order |
| Reviewing professional | Name/role of the buyer's responsible reviewer; approval authority |
| Required submission convention | Client/agency template, figure numbering, title block, disclaimer |
| Review checkpoint | Named reviewer, feedback route and acceptance procedure |

Do not request secrets, private client records or restricted datasets in a
public issue or initial inquiry email. The requester is responsible for
confirming data rights and the authority of any professional reviewer.

## 2. Source and technical readiness

| Field | Required agreement before production |
| --- | --- |
| Input format and rights | File/URI inventory, owner, permission for use and redistribution |
| Source register | Dataset, publisher, version, acquisition/retrieval date, effective date if known |
| CRS and units | Declared source CRS, proposed output CRS, measurement basis and transformations |
| Spatial coverage | Geographic/time extent, missing and partially covered areas |
| Data QA | Required fields, unique IDs, geometry quality, no-data handling and reconciliation |
| Interpretation boundaries | Questions that require field verification or licensed local expertise |

An empty intersection is not evidence that a site is unconstrained. Report
verified **no mapped intersection** separately from **partial, missing,
unavailable or unverified source coverage**. Do not infer unknown source
accuracy, effective dates or regulatory determinations.

## 3. Commercial scope and change controls

- **Included output:** agree a named map/figure index and the specific PDF,
  GIS/native, source-register and QA artifacts before a fee is proposed.
- **Complexity:** price/scoping factors can include parcel count, page count,
  extent/scale, data readiness, coordinate transformations, theme variations,
  title-block compatibility and post-export QA.
- **Dependencies:** data purchases, third-party rights, client review windows,
  inaccessible sources, specialist signoff and required desktop software.
- **Revision allowance:** define how many review cycles are included and what
  counts as correction versus new figures, new analysis or replaced input.
- **Schedule:** the start date and delivery window depend on complete/usable
  input and mutually agreed availability; no standard turnaround is promised.
- **Operations:** client manages agency submission and professional
  interpretation. Future refresh, hosting and maintenance require separate scope.

**Proposed acceptance wording:** "The deliverable is accepted when the agreed
figure inventory is present; output opens in the specified environment; page
identifiers, sources, dates, units, coverage statuses and known gaps match the
approved input/register and QA evidence; exceptions are documented for the
reviewing professional." Adapt this wording to the actual contract.

## 4. Handoff validation — complete for each delivery

- [ ] Figure/page IDs and counts reconcile to the accepted figure index.
- [ ] Input-to-output parcel IDs, feature counts, CRS/units and flags reconcile.
- [ ] Every source has ownership/rights, version/date/coverage and limitations.
- [ ] Partial/missing/unverified coverage is explicitly shown and described.
- [ ] Map labels, legend, scale, north reference, extent and page size are legible.
- [ ] PDF/other delivered files reopen; native project references resolve after relocation.
- [ ] Output inventory, manifest checksums, methodology and QA exceptions are retained.
- [ ] Client reviewer records disposition of open questions, changes and signoff.
- [ ] Distribution rights and handling of private locations/attributes are approved.
- [ ] No language implies field delineation, jurisdictional findings, boundary
      surveying, Phase I ESA, engineering opinion or regulatory approval.
